## 🚀 Key Features

### 1. 🎮 Real-Time WebGL 3D World (`Three.js`)
- **Procedural Marine Ecosystem**: 450+ physical rising bubbles, 35+ dynamic schooling fish with phase-offset swimming algorithms, and 7 bioluminescent bell jellyfish with pulsating tentacles.
- **Volumetric Caustics & Light Shafts**: Additive blending cone godrays that rotate and breathe with solar illumination.
- **Interactive 3D Underwater Buggy**: Fully modeled amphibious vehicle with carbon-composite chassis, bubble dome, rolling balloon wheels, and dual front spot-headlights dynamically casting light across the seabed.
- **Fluid Current Sway**: The camera floats inside simulated buoyancy currents, gently drifting as you explore.

### 2. 🥽 5D Cockpit Visor & Multi-Sensory Immersion
- **360° Drag & Gyroscope Look-Around**: Click-and-drag on desktop or physically tilt your smartphone via the `DeviceOrientation` API to pan the camera across the seabed.
- **Physical Device Haptics (`navigator.vibrate`)**: Genuine mobile phone tremors synchronized with Buggy overdrive thrusters, Poseidon alarms, and seismic fault line tremors.
- **Procedural Web Audio Engine**: Zero external audio file dependencies. Real-time synthesized low-frequency ocean drones, resonant hydrophone sonar pings, bubble chirps, deep diver respirators, and Mariana trench heartbeats.
- **Sensory Actuator Dock**: Interactive triggers for Tectonic Shockwaves, Hydrothermal Plumes, Buggy Thruster Overdrives, and Abyssal Heartbeats.

### 3. 👁️ Instant "Ocean View" Mode (Zero Clutter)
- A dedicated **Ocean View** toggle in the navigation bar lets users fade out all text cards with a single tap.
- Explore the 3D marine world, watch the marine life, and drive with the Underwater Buggy with **100% unobstructed view**.
- Restore the story overlay anytime via the floating pill.

### 4. 🤖 Sentient Companion: The Underwater Buggy
- **Conversational Neural Interface**: Interactive dialogues charting Buggy's emotional awakening from cold calculation to genuine empathy.
- **Headlight Switcher**: Toggle between High-Beam penetration and Stealth exploration.
- **Overdrive Thruster Test**: Triggers particle acceleration and sub-bass vibration.

### 5. 🔒 Spoiler-Gated Deep Lore Dossier
- Secure gateway protecting pivotal story arcs:
  - **Mu Federation**: Sovereign undersea alliance and the roots of surface distrust.
  - **Atlantis Civilization**: Ancient militarized empire and forgotten war machines.
  - **Poseidon Autonomous AI**: Algorithmic decision trees misinterpreting volcanic tremors as surface attacks.
  - **Devil's Horn Retaliation Missiles**: An ominous monument to the consequences of ancient conflict.
  - **Triline / Trilain**: The elderly Mu survivor whose dismissed testimony holds the critical truth.
  - **Ocean Stewardship**: *"The ocean remembers what we leave behind."*

### 6. 🇮🇳 India Theatrical Premiere Hub (2 October 2026)
- Comprehensive theatrical release dossier:
  - **Languages**: Hindi, Tamil, Telugu dub selectors.
  - **Formats**: 2D, 4DX, and MX4D where available (First Doraemon movie with simultaneous 4DX/MX4D release).
  - **Distribution**: TV Asahi & PVR INOX Pictures association.
  - **Partners**: Black White Orange (BWO) & Happening 365 Synergies.
  - **One-click Ticket Reminder**: Integrated for BookMyShow / PVR INOX launch.

### 7. 🎁 Hidden Easter Eggs
- **Doraemon's Golden Bell**: Tap the bell in the top navigation 3 times to trigger a secret cat-call homing chime and pocket sparkles.
- **Submerged Anywhere Door**: Discover Fujiko F. Fujio's iconic pink door resting on the deep ocean floor.

## 💻 Getting Started Locally

### Prerequisites
- **Node.js**: `v20.x` or higher
- **npm**: `v10.x` or higher

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/<your-username>/doraemon-undersea-devil-3d.git
   cd doraemon-undersea-devil-3d
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Launch the development server:**
   ```bash
   npm run dev
   ```

4. **Open in browser:**
   ```
   http://localhost:3000
   ```

5. **Build for production:**
   ```bash
   npm run build
   npm run start
   ```
